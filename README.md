# Global Refriauto — Propuesta de Landing Page Corporativa

Prototipo y demo interactiva de la **Landing Page Corporativa para Global Refriauto**, empresa especializada en climatización, refrigeración automotriz (HVAC) y mecánica industrial vehicular en la República Dominicana.

Este desarrollo sirve como demostración visual (UI/UX) y de propuesta comercial para el cliente (**Juan Roberto Rojas Musa / "Musan"**), previo a la fase de integración con el sistema a la medida en **C# (.NET)** para gestión de taller, facturación y Comprobantes Fiscales (NCF).

---

## 🛠️ Tecnologías Utilizadas

- **HTML5 Semántico:** Estructura limpia y optimizada para accesibilidad y SEO local.
- **CSS3 Moderno:** Variables CSS (`:root`), Grid Layout, Flexbox, respuestas adaptativas (`clamp()`, `@media queries`) y diseño Glassmorphism.
- **Estructura Monolítica:** Todo el código (HTML y CSS) concentrado en `index.html` para un despliegue ultra-rápido en producción sin errores de rutas estáticas.
